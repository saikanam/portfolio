# Callout Demo

This page demonstrates various types of Obsidian-style callouts supported by our portfolio.

## Basic Callouts

> [!note] This is a note
> This is a basic note callout with some important information.

> [!tip] Pro Tip
> Here's a helpful tip that can save you time and effort.

> [!important] Important Information
> This is something you really need to pay attention to.

> [!warning] Warning
> Be careful when following these instructions.

> [!danger] Danger Zone
> This could be potentially harmful if not done correctly.

## Collapsible Callouts

> [!info]+ Expandable Info
> This callout is collapsible and open by default.
> You can click the title to collapse it.

> [!question]- Collapsed FAQ
> This callout starts collapsed.
> Click the title to expand and see the content.
